# Disenchant Odds (WoW Forever)

Hover any green, blue or purple weapon or armor. The tooltip then shows what it disenchants
into and the chance of each result, for example:

    Disenchants into:                 Enchanting 150
      1-2x Dream Dust                            75%
      1-2x Greater Nether Essence                20%
      1x Large Radiant Shard                      5%
      Average value (Auctionator)            1g 20s

- The Enchanting skill needed is green when your skill is high enough, red when it isn't, and
  gray on characters that don't know Enchanting.
- If you use Auctionator, the average auction value of the results is shown too
  (from Auctionator's last scan; a `*` means some material prices are unknown).

## Settings

Esc > Options > AddOns > Disenchant Odds, or `/deodds`. You can show the lines only while
holding Shift, only on characters with Enchanting, and turn the skill, value and icons on or off.

## Where the numbers come from

The Classic Era disenchanting tables (warcraft.wiki.gg "Disenchanting tables" and
"Disenchanting"), which match Forever's Classic item list. If Forever has changed its
disenchant rules, the real results can differ. A few items can't be disenchanted at all
(some quest and special items); the tooltip still shows the table for them.
